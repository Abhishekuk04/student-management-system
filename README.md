# Student Management System

A simple Student Management System built using Python, Streamlit, Object-Oriented Programming (OOP), and JSON. The application provides separate functionality for managing students and teachers, including student registration, login, marks management, and viewing student details.

## Features

* Student registration
* Teacher registration
* Student login
* Teacher login
* Student details management
* Add and manage student marks
* View student details
* JSON-based data storage
* Basic input validation
* Interactive Streamlit interface

## Technologies Used

* Python
* Streamlit
* Object-Oriented Programming (OOP)
* JSON

## OOP Concepts Used

* Classes and Objects
* Inheritance
* Abstraction
* Encapsulation
* Methods

## Project Structure

```text
student-management-system/
│
├── main.py
├── app.py
├── school_data.json
└── README.md
```

### `main.py`

Contains the backend logic and core functionality of the application.

### `app.py`

Contains the Streamlit interface and connects the frontend with the application logic.

### `school_data.json`

Stores student and teacher information and other application data.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Abhishekuk04/student-management-system.git
```

### 2. Navigate to the project folder

```bash
cd student-management-system
```

### 3. Install Streamlit

```bash
pip install streamlit
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## Project Purpose

This project was developed to practice Python programming, Object-Oriented Programming, JSON data handling, and building interactive web applications using Streamlit.
